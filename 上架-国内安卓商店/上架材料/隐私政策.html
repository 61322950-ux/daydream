白日梦
隐私政策

更新日期：2026年9月3日 · 生效日期：2026年9月3日

「白日梦」（以下简称"本应用"）是一款离线文字体验应用：通过内置的梦境生成引擎，为用户生成一段可阅读、可交互的白日梦文本，并提供梦境档案的本地保存功能。

我们非常重视你的隐私。本政策将向你说明：本应用不收集、不使用、不存储、不对外提供任何你的个人信息。请你仔细阅读以下内容。

一、我们不收集任何信息

  • 本应用不需要注册账号，不要求你提供手机号、邮箱或任何身份信息；
  • 本应用不接入任何统计、广告、推送 SDK，不会追踪你的使用行为；
  • 本应用不会读取你的通讯录、相册、位置、麦克风、摄像头等任何手机权限。

二、数据如何存储（仅保存在你的设备上）

你在本应用中生成的梦境记录（梦境名称、时间、意象、醒物等）通过设备本地的存储机制（localStorage）保存在你自己的手机里。这些数据：

  • 不会上传到任何服务器；
  • 我们（开发者）无法查看；
  • 你可以随时在应用内"梦境档案 → 清空档案"中彻底删除。

三、关于"AI 入梦"功能（可选功能）

本应用的默认梦境由内置引擎在设备本地生成，完全离线，不产生任何网络请求。

本应用额外提供一个可选项"AI 入梦"：只有当你主动在设置中开启、并自行填入你自己在大模型服务平台的 API Key 时，应用才会把你输入的梦境种子词与设备当前时间发送给你所填写的接口地址，用于生成梦境文本。此功能下：

  • 你的 API Key 仅保存在你的设备本地，我们无法获取；
  • 发送的内容仅限你输入的种子词与时间信息，不含任何身份信息；
  • 该请求由你填写的第三方服务（如智谱开放平台）接收与处理，其数据处理遵循该第三方的隐私政策；
  • 你不开启此功能，本应用不会产生任何网络通信。

四、权限说明

本应用仅申请 网络（INTERNET） 权限，且仅在你开启上述"AI 入梦"功能时才会实际使用网络。除此之外，本应用不申请、不使用任何其他权限。

五、未成年人保护

本应用内容为文学化的梦境文本，不含暴力、恐怖、色情等内容，适合全年龄段使用。本应用不收集未成年人信息，也不含任何付费或广告内容。

六、政策的更新

若本应用功能发生变化（例如新增需要收集信息的功能），我们将在本页面更新本政策并修改更新日期。重大变更将在应用内显著位置提示。
