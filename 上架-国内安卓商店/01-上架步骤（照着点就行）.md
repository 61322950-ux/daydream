# 白日梦 · 国内安卓商店上架指南（零编程版）

> 照着点就行。全程不需要写代码。
> 总览：**5 件事，总花费约 ¥400–700，总周期约 1.5–2.5 个月**（主要是等证书和备案，等待期间可以先把网页版上线）。

| 步骤 | 事项 | 花费 | 周期 | 依赖 |
|---|---|---|---|---|
| ① | 打出 APK 安装包（HBuilderX 云打包） | 免费 | 30 分钟 | 今天就能做 |
| ② | 办「APP 电子版权认证证书」（代替软著） | 约 ¥300–500 | 10–15 个工作日 | **最先启动** |
| ③ | 工信部 App 备案 | 免费（但需一台云服务器约 ¥100/年） | 约 30–40 天 | 需要②的证书编号 |
| ④ | 部署网页版 + 隐私政策链接 | 免费 | 10 分钟 | 随时 |
| ⑤ | 五大商店注册 + 提审 | 免费 | 各 1–3 个工作日 | 需要①③④齐 |

> ⚠️ 为什么顺序是这样：2026 年各商店普遍**强制**两项材料——[软件著作权/电子版权证明](https://juejin.cn/post/7640041577754787894) 和 [工信部 App 备案](https://blog.csdn.net/guanzhen581/article/details/160400674)，且备案表中要填证书编号，所以②必须先于③。另外**应用名、证书名、备案名三者必须一致**（[小米官方规范](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=1796)），全程统一叫「白日梦」。

## 第 ① 步：打出 APK 安装包（今天，30 分钟）

用 HBuilderX 的"云打包"：打包在 DCloud 的服务器上完成，你只负责点按钮。

1. **下载 HBuilderX**：浏览器打开 `https://www.dcloud.io/hbuilderx.html` → 下载 **标准版** → 安装（跟普通软件一样下一步）。
2. **注册 DCloud 账号**：打开 HBuilderX → 右上角人像图标 → 注册/登录（手机号即可）。
3. **打开工程**：菜单「文件 → 打开目录」→ 选择本套件里的 **`HBuilderX工程-白日梦`** 文件夹（App 的全部代码和图标已配好）。
4. **获取 appid**：双击项目里的 `manifest.json` → 会打开可视化界面 → 点 **「重新获取appid」** 按钮 → `Ctrl+S`（Mac `Cmd+S`）保存。
5. **云打包**：菜单「发行 → 原生App-云打包」→ 弹窗里：
   - 勾选 **Android**
   - **Android 包名**填：`com.你的名字拼音.daydream`（例如 `com.wangkun.daydream`，**定好别再改**，后面备案和商店都用它）
   - 证书选 **「使用公共测试证书」**（个人上架先用这个跑通；以后可按 DCloud 文档换成自有证书）
   - 勾选「打正式包」→ 点 **打包**
6. **等 5–10 分钟**：菜单「视图 → 控制台」会显示打包进度，完成后给一个 **APK 下载链接**。
7. **装到手机上试试**：把 APK 通过微信"文件传输助手"发到手机 → 打开安装（如提示未知来源，允许一次）→ 白日梦应该已经带图标装好了。

> ✅ 检查点：手机上打开 App，入梦、转清醒、醒来、档案都正常 → APK 就绪。保存好这个 APK 文件，第⑤步要上传它。

## 第 ② 步：办「APP 电子版权认证证书」（最先启动，约 ¥300–500）

国内商店要求的"版权证明"二选一：
- **软件著作权登记（软著）**：官方渠道 [register.ccopyright.com.cn](https://register.ccopyright.com.cn/registration.html#/registerSoft) 登记本身**免费**，但[当前周期约 3–4 个月](https://zhuanlan.zhihu.com/p/1925484096773129786)；
- **APP 电子版权认证证书**：华为、应用宝、小米、OPPO、vivo、阿里、360、百度[都认](https://market.aliyun.com/products/56838014/cmgj00070288.html)，**10–15 个工作日**出证，个人上架的性价比之选。

**推荐走电子版权认证**，步骤：

1. 打开阿里云云市场，搜索「**APP电子版权认证**」（或搜"电子版权认证联合服务平台"），选销量高的服务商下单（标准版 10–15 工作日，急用可选 3 工作日加急）。
2. 按店铺客服指引提交材料（都是现成的）：
   - 身份证正反面照片（著作权人=你本人，必须和后面商店账号实名一致）；
   - 软件信息：全部从 [`上架材料/商店信息填写对照表.md`](上架材料/商店信息填写对照表.md) 的"上架版权证明"表格复制——**软件全称填「白日梦移动应用软件（简称：白日梦）」**；
   - 源程序材料：客服一般要求提交部分源代码文档。不用怕：把本工程 `engine.js` 和 `app.js` 两个文件用文本编辑器打开，复制内容粘到 Word，页眉写"白日梦移动应用软件 V1.0 源程序"，导出 PDF 交上去即可（代码里中文注释齐全，审核好过）。
3. 出证后你会拿到**证书编号和 PDF 证书**——第③步和第⑤步都要用。

> 想省钱且不急：直接走官方软著（免费，等 3–4 个月），出证后还可免费做"电子版权核发"（15 个工作日）。

## 第 ③ 步：工信部 App 备案（免费，但约 30–40 天，尽早启动）

2024 年起，国内所有商店上架新应用都必须填 **App 备案号**（[政策要求](https://blog.csdn.net/guanzhen581/article/details/160400674)）。备案通过云服务商提交，个人（自然人）主体可以办。

1. **买一台最便宜的云服务器**：阿里云或腾讯云的"轻量应用服务器"，最便宜的套餐（约 ¥50–100/年，仅用于挂备案，App 本身不需要服务器）。买完实名认证。
2. **进入备案控制台**：搜「ICP 备案 / App 备案」→ 选 **App 特殊场景备案（App 备案）** → 主体选"个人"。
3. **填写 App 信息**（照抄）：
   - App 名称：**白日梦**（必须和证书、商店名一致）
   - 平台：Android
   - App 包名：第①步填的那个（如 `com.wangkun.daydream`）
   - 证书/版权编号：第②步拿到的电子版权证书编号
   - 是否提供信息服务：按实际勾选（本应用默认离线，可勾"否/仅可选第三方AI功能"，以备案页面提示为准）
4. **人脸核验** → 提交 → 云服务商初审（1–2 天）→ 管局审核（约 20–30 天）。
5. 通过后你会得到类似 `X ICP备XXXXXXXX号-XXXXX` 的 **App 备案号**——第⑤步每家商店都要填。

> 备案期间正好等证书，两条线并行；等待期间把第④步做了。

## 第 ④ 步：部署网页版 + 隐私政策链接（10 分钟，免费）

商店要求隐私政策必须是**公网可访问的链接**。顺便把网页版也上线了（一鱼两吃）。

1. 打开 `https://app.netlify.com` → 用邮箱注册（免费）。
2. 首页有个拖拽上传区（"Drag and drop your site output folder here"）。
3. 把整个 **`daydream-app`** 文件夹**里的内容**（index.html、style.css、app.js、engine.js、icons 等）拖进去 → 几秒后得到一个网址，例如 `https://random-name.netlify.app`。
   - 换好记的名字：Site settings → Change site name → 改成 `bairimeng-你的名字` → 网址变成 `https://bairimeng-xxx.netlify.app`。
4. 把 `上架材料/隐私政策.html` 也一起拖进去（同一文件夹里即可）。
5. 打开 `隐私政策.html`，**用记事本把里面的联系邮箱 `your-email@example.com` 改成你自己的**（改完本地文件再重新拖一次），得到隐私政策链接：
   `https://bairimeng-xxx.netlify.app/隐私政策.html`（建议把文件改名为 `privacy.html`，链接就是 `https://bairimeng-xxx.netlify.app/privacy.html`）。

> 这个网址同时就是你网页版 App 的地址，手机浏览器打开即可使用，也能"添加到主屏幕"。

## 第 ⑤ 步：五大商店注册 + 提审（材料全部照抄对照表）

每家流程相同：**注册开发者账号 → 实名认证（身份证+人脸）→ 创建应用 → 填信息（照抄 `上架材料/商店信息填写对照表.md`）→ 上传 APK + 证书 + 截图 → 填备案号 → 提交审核**。建议按审核友好度从华为开始。

### 华为 AppGallery（华为应用市场）
- 入口：`developer.huawei.com` → AppGallery Connect
- 个人可注册；创建应用时包名必须与 APK 一致
- 需上传：电子版权证书、软著或其认可的权利证明、隐私政策链接、备案号
- 审核一般 1–2 个工作日

### 小米应用商店（澎湃OS）
- 入口：`dev.mi.com`
- 个人可注册；小米对名称一致性和备案要求最严格（[规范见此](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=1796)、[版权证明指南](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=1709)）
- 权属证明传电子版权证书；资质审核通过后才能提审应用，**先注册先排队**
- 审核一般 1–3 个工作日

### OPPO 软件商店
- 入口：`open.oppomobile.com`
- 个人可注册；有隐私合规自动化检测，隐私政策链接必须真实可打开
- 审核一般 1–3 个工作日

### vivo 开放平台
- 入口：`dev.vivo.com.cn`
- 个人可注册；同样需要版权证明 + 备案号 + 隐私政策
- 审核一般 1–3 个工作日

### 腾讯应用宝
- 入口：`open.qq.com`（微信/QQ 登录后绑定开发者身份）
- 个人可上架；需上传电子版权证书、备案号、隐私政策链接
- 审核一般 1–3 个工作日

## 常见驳回原因与对策

| 驳回理由 | 对策 |
|---|---|
| 名称不一致 | 应用名 / 证书名 / 备案名统一为「白日梦」体系 |
| 隐私政策不达标 | 用 `隐私政策.html`（已按"不收集任何信息"撰写，逐条对应本应用实际行为）；链接必须能直接打开 |
| 缺版权证明 / 备案号 | 等第②③步完成再提审，别裸奔 |
| 权限与功能不符 | 权限申报填"INTERNET 仅用于可选 AI 功能"，对照表里已写好 |
| 截图与实际不符 | 用真机截图，别用网图 |

## 以后更新版本怎么办

1. 改完代码后：`manifest.json` 里 `versionName` 改成 `1.0.1`，`versionCode` 改成 `101`（每次+1）。
2. 重新云打包 → 得到新 APK → 到各商店后台"提交新版本"上传。
3. **签名证书保持一致**：一直用 DCloud 公共证书即可保持一致；换自有证书后无法覆盖更新。
